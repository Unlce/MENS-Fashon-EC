# MENS FASHION - メンズECサイト

エレガントでミニマルなデザインのメンズファッションECサイトです。

## デザイン参考

このサイトは以下のレディースECサイトのデザインを参考に作成されました：

- [EIMY ISTOIRE](https://eimyistoire.com/)
- [ANDREA&Co.](https://www.andrea-co.jp/)

## デザイン特徴

### カラーパレット
- **メインカラー**: ホワイト (#ffffff)、ブラック (#000000)
- **アクセントカラー**: ダークブラウン (#170f0f)、セールレッド (#e32c2b)
- **ボーダー**: ライトグレー (#d9d9d9)

### フォント
- **セリフフォント**: EB Garamond（見出し用）
- **サンセリフフォント**: Noto Sans Japanese（本文用）

### レイアウト
- 最大幅: 1360px
- レスポンシブデザイン対応
- ミニマルでエレガントなグリッドレイアウト

## 使用方法

### ローカルで表示

1. リポジトリをクローン
```bash
git clone <repository-url>
cd MENS-Fashon-EC
```

2. `index.html` をブラウザで開く
```bash
open index.html
```

または、ローカルサーバーを起動（推奨）
```bash
# Python 3を使用する場合
python3 -m http.server 8000

# Node.jsを使用する場合
npx serve
```

3. ブラウザで `http://localhost:8000` にアクセス
